# メンバーの設定

ふりかえりで使う名前と共有先を、一度確認して使い回します。すでに分かっている項目や保存済みの希望を毎回聞き直しません。

## 初回に聞くこと

- 「ふりかえりで使う、あなたのあだ名は何ですか？」
- 「どのSlackワークスペース・チャンネルへ投稿しますか？」
- 「ふりかえりは、内容を確認してから投稿・毎回自動で投稿・投稿しない、のどれにしますか？」
- 「GitHubへのコミット・pushも行いますか？ 毎回確認・このプロジェクトでは自動・行わない、から選べます。」

質問はまとめて提示できます。未回答は自動投稿や自動pushへの同意として扱いません。名前は本人の希望を使い、GitHubの表示名やメールアドレスから推測しません。

## 接続と共有先を確かめる

使っているAIのSlackプラグイン・接続機能を確認します。未接続なら、本人のアカウントで接続する画面と操作を案内します。利用できるチャンネル情報から、ワークスペース、チャンネル名とID、投稿できる接続を確かめます。同名のチャンネルが複数あれば、対象を質問します。Slackを読む接続と投稿できる接続は別に確認します。

設定の確認だけではテスト投稿しません。ふりかえりの投稿は、本人が選んだ方法で行います。Webhook URLやトークンを要求したり、設定ファイルへ保存したりしません。投稿機能がないクライアントでは、接続待ちとして残し、使えるプラグインの設定や本人が投稿できる下書きを案内します。

GitHub共有を選んだ場合は、対象アプリの実際のリポジトリ、remote、ブランチを確認します。チームのスキル配布リポジトリと、メンバーのアプリを混同しません。共有する対象や方針が変わる場合は、その差だけを確認します。

## 本人のPCへ保存する

保存先はmacOS・Linuxでは`~/.config/team-ai-connectors/profile.json`、Windowsでは`%APPDATA%/team-ai-connectors/profile.json`です。共有リポジトリの中には保存しません。既存ファイルがあれば読み、他のプロジェクトの設定を保持して更新します。ファイルを本人以外へ共有しません。

```json
{
  "schema_version": 1,
  "nickname": "本人が決めた名前",
  "projects": {
    "github.com/owner/app-repository": {
      "slack": {
        "workspace": "確認したワークスペース",
        "channel_id": "確認したチャンネルID",
        "channel_name": "確認したチャンネル名",
        "post_mode": "confirm"
      },
      "github": {
        "push_mode": "ask",
        "remote": "origin",
        "branch": "確認したブランチ"
      }
    }
  }
}
```

`projects`のキーには、実際のGitHub remoteから確認した`ホスト名/owner/repo`を使います。SSHとHTTPSの違いをそろえ、末尾の`.git`と認証情報を除きます。GitHub Enterpriseでは実際のホスト名を含め、同名の別リポジトリと区別します。GitHubリポジトリがない作業は、対象フォルダーの絶対パスをキーにします。例の値をそのまま保存せず、分かった項目だけを記録します。

`post_mode`は`confirm`・`auto`・`off`、`push_mode`は`ask`・`auto`・`off`です。未選択時はそれぞれ`confirm`と`ask`を使います。`auto`は本人が明示的に選んだプロジェクトと共有先だけに適用します。別プロジェクトや別ブランチへ設定を流用しません。GitHubの自動共有を選ぶ前に、対象作業の変更をコミットし、通常のpushを行う設定であると説明します。

ローカルファイルを使えないクライアントでは、その会話内の希望として扱います。PCへ保存したとは報告せず、次の会話へ設定が引き継がれると約束しません。
