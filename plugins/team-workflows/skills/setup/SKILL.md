# 初期設定

説明と質問は日本語を基本にし、ユーザーが別の言語を指定したら従います。設定方法を説明するだけでなく、依頼された範囲で導入と確認を進めます。

## 今の環境を確認する

1. 使用中のAIクライアント、OS、作業フォルダー、導入済みのスキルと接続を確認します。ツールや設定から分かる事実は自分で調べ、分からない使用環境だけ質問します。
2. このチームのリポジトリやマーケットプレイスが既にあれば使い回します。同じ内容を別の場所へ複製したり、既存の設定を初期化したりしません。
3. 必要な導入先と依頼範囲を整理します。「natural-japaneseも入れて」という依頼があれば、その導入を含めます。依頼されていないサービスの認証や設定は増やしません。
4. 環境に合う手順だけ、[導入と確認の手順](references/installation.md)から読みます。ブラウザー版のChatGPTと、ローカルで作業するCodex・Claude Codeの設定を混同しません。

## 導入して確かめる

- 設定前に現在の導入状況を確認します。同じ版が既に使える場合は再導入せず確認へ進みます。既存の別の版を入れ替える必要があれば、変更内容と依頼範囲を照合します。
- ローカルの変更が可能で、依頼に含まれる導入は実行します。対応するCLIがない場合は公式の導入案内を示し、ユーザーが操作する場所を具体的に伝えます。
- `natural-japanese`は、チームのカタログが参照する`coji/natural-japanese`の配布物を使います。同名の短い代用品を作ったり、ローカルに偶然見つかったファイルを配布元として扱ったりしません。
- 日本語文章の検査に必要な`uv`などの依存ツールは、導入したスキルの現在の指示を確認します。依存ツールが使えなければ、その検査は未確認として残します。
- パスワード、トークン、Webhook URLはチャットや共有ファイルで受け取りません。各サービスのブラウザー認証や、本人のローカル環境から設定します。
- スキルの導入、文章検査、サービスへの接続をそれぞれ確認します。接続確認では閲覧できるページやメッセージを読みます。Slackへの投稿やGitHubへの書き込みは、別途依頼された操作だけ行います。

## 完了を伝える

導入したもの、既存のまま使えたもの、実際に確認したこと、残っている本人の操作を短く報告します。新しいセッションが必要なら明記します。

`natural-japanese`は一覧に表示されることに加え、日本語の短い文を対象に実行し、スキルが求める検査を実行できるか確認します。画面に名前があるだけで、接続や検査まで成功したとは報告しません。依存ツールの導入やサインインが保留でも、独立して進められる設定は続けます。
